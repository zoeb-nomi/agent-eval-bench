# gov-services: Arabic vs English gap

Two tracks of 500 pairs each, every item in English and Arabic with both source URLs and the date read: UAE government services (closed-book) and consumer support (answer from an official help page). Seven models run through OpenRouter on all 2,000 items each (14,000 runs; about $7.7 in total); every raw answer, latency and cost is in `results/raw/`. Tables with 95% intervals, the English to Arabic gap, judge agreement and run cost: `results/arabic_gap.md`; chart-ready data: `results/arabic_gap.csv`. Arabic-first models (Jais, Falcon Arabic, ALLaM, Fanar) are not offered on OpenRouter and are named as unavailable in the report. Rebuild the sets: `python scripts/build_sets.py`; run (cached, resumable, stops above a money cap): `python scripts/run_scale.py pilot` then `full`; report: `python scripts/report_scale.py` (needs `OPENROUTER_API_KEY`). Scorer fix (CHE-289): `python scripts/rerun_empty.py` (pilot, projects cost, stops above 1.4 USD) then `--go`; `python scripts/check_scorer.py` (code scorer vs judge, 300 per language); then `python scripts/report_scale.py`. `scripts/fixtures/` holds the test fixtures; tests: `pytest scripts/tests`. The earlier six-model small run is kept (`run_bench.py`, `report_gap.py`).

Exact items (number, fee, duration, document list, yes/no) are scored by code, the rest by a cheap judge model; on a random sample of 320 answers a second judge agreed on 95%. Agreement with a human is not yet measured: `results/human_label_sheet.csv` awaits a human label. Nothing here makes a claim about any company's product.
